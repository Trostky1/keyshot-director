FAQ

Questions we expect

Does Director save my KeyShot scene?

Never. Director leaves your scene unsaved, so you review the result and save it in KeyShot yourself.

Which KeyShot version does it need?

KeyShot Studio 2026.2 on Windows 11 is the verified setup. Director talks to the open scene through KeyShot’s scripting window.

Where do my reference images go?

Reference images and KeyShot previews go to the assistant you choose in Settings, only for the request that needs them. Saved style collections stay on this computer.

Can I use Director without an AI account?

Director can still run basic commands in offline mode. Reference matching and the conversation need an assistant.

Does it work on macOS?

Physical macOS integration is still unverified. Windows 11 with KeyShot Studio 2026.2 is the verified setup.

Why are Metallic and Displacement not built into materials?

Those paths are paused for reliability. Director builds a simple Plastic material from Base Color, Roughness, a Normal or Bump map and optional AO, and lists every skipped file.

Measurement area and attempt limits

Draw a tight rectangle around the product or detail in your reference. Director measures the selected KeyShot part’s projected bounds there, or the full product if no part is selected. Other objects inside the rectangle can affect the score. If you do not set an area, Director keeps the first result.

Keep fixed during refinement

Each match is limited to 12 preview renders or 8 minutes. A result is kept only when its improvement is larger than normal render variation. The score tracks the selected goal; it does not measure overall similarity to the reference.

For lighting matches, the reference and KeyShot previews go to your selected AI provider. Materials remain untouched. Save your scene in KeyShot to keep the result.
