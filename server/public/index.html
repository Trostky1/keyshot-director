Import a texture set

Use actual channel maps—not reference photos—to build a reusable KeyShot finish.

Original maps stay local

For downloads like Poliigon_BoucleFabricBubbly_7827, choose the product folder or its 2K/4K subfolder. The importer keeps channel maps and MaterialX metadata, and leaves preview images out of the shader set.

A folder import recognizes common Base Color, Roughness, Metallic, Normal, Displacement, Bump, Specular and AO filenames. It copies the source files unchanged into Director’s local Materials folder. A .mtlx file is read as conversion metadata because KeyShot does not directly import MaterialX.

Before building, select the intended part in KeyShot. Auto chooses a dielectric shader for fabrics and plastics, a Metal shader for metal assets, and the Metal + Plastic label graph for rust / patina. Choose the projection that matches the part; UV coordinates avoid projection seams when the model has usable UVs. Maps use a 30 cm tile. Zero-scale displacement maps are preserved but never connected to geometry.

Poliigon workflow in KeyShot

For the full Poliigon graph, select the model in Project → Scene, open its material, choose Advanced, then Material Graph. Drag in the maps; connect Mapping 2D to each texture map's UV Mapping input and set each map's Mapping Type to Node. Connect Base Color to Diffuse, Roughness through Color To Number to Roughness, and Normal to Bump (Poliigon recommends negative normal strength). Only connect Displacement through a Displace node when the source material specifies a non-zero displacement scale.

For mixed metal and rust, build a Metal base with a Plastic label and use an inverted Metalness map to drive the Plastic label opacity. Import an HDRI through Library → Environments, double-click to assign, then tune it under Project → Environment.

Director builds this graph automatically when the required maps are present. Ambient Occlusion and arbitrary MaterialX graphs are still kept as source files without automatic conversion. Select the target object in KeyShot before building.
